Good to know

Questions, answered

Is Flow Music free?

Yes — completely free and open source under GPL-3.0. The few ads on the manual download page are what keep development going.

Do in-app updates work?

OTA updates have been removed. Download new versions manually from this page or the releases list.

Which file should I install?

Just the universal APK from the latest release. It contains every ABI, so it runs on any phone.

Why is my install blocked?

Android blocks apps installed outside the Play Store by default. When prompted, allow installs from your browser or file manager — the app is signed and safe.

Do I need an account?

No sign-up, no login. The app talks to YouTube Music directly, and Flow Brain runs entirely on your device.
